How it works

From plaintext to verified plaintext, through the air.

  1. 01

    Plaintext

    receipt, prescription, voucher or free message

    ›
  2. 02

    postcard + LZ4

    compact binary, LZ4 only if it shrinks

    ›
  3. 03

    Optional E2EE

    ChaCha20-Poly1305 · PBKDF2-HMAC-SHA256 · fresh salt

    ›
  4. 04

    CRC32 + Ed25519

    checksum then strict signature over header, payload and CRC

    ›
  5. 05

    4-FSK sound ∥ LT QR

    Reed-Solomon modem or fountain-coded QR burst

    ›
  6. 06

    Verified plaintext

    or an exact rejection code

All cryptography, compression, DSP and coding run in a Rust crate compiled to WebAssembly. The page only moves samples and pixels: speaker, microphone, screen and camera.

Verification order (fails closed at the first broken layer): size → preamble → version and flags → length → CRC32 → decryption → bounded LZ4 → schema → keyring → strict Ed25519. Try it live in the Simulation tamper lab: click any byte of the frame.

Integrate in your app

GhostPacketSDK (package packages/ghostpacket-sdk, shared by every app of the skeleton) exposes sealMessage, verifyFrame, transmitAcoustic / receiveAcoustic, transmitOptical / receiveOptical, exportGpktFile / importGpktFile, and queueProof / syncProofs / enableAutoSync for the server-side verifier.

// npm run build:sdk && npm pack ./packages/ghostpacket-sdk/dist, then npm install ghostpacket-sdk-0.3.0.tgz
// ESM package; the WASM and the microphone worklet ship inside it.
import { GhostPacketSDK, downloadFile } from "ghostpacket-sdk";

const gp = await GhostPacketSDK.load();          // ephemeral Ed25519 key for this tab
console.log("My fingerprint:", gp.identity.fingerprint);

const sealed = gp.sealMessage(
  { sender: "Ndiob health post", title: "Rx #0815", message: "Artemether 4 tablets x2/day, 3 days" },
  { passphrase: sharedPassphrase },               // optional end-to-end encryption
);
if (!sealed.ok) throw new Error(sealed.error.code);

await gp.transmitAcoustic(sealed.value.frame);    // speaker, robust 4-FSK
// or: gp.transmitOptical(sealed.value.frame, canvas, abort.signal)
downloadFile(gp.exportGpktFile(sealed.value.frame, "rx-0815.gpkt"));
